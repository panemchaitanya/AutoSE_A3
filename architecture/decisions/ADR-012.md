# ADR-012: Prefer the available lite model while preserving outcome checks

- Status: Accepted provisionally; availability evidence, not model-quality proof
- Supersedes: ADR-006 default role tiering
- Decision area: D6

## Context

Flash Developer calls in runs 45175065687, 45175508632, 45175512084,
45175516167 and 45175520241 failed through timeouts/disconnection. The
paced lite continuation 45177637212 completed implementation and testing
for issue 1. Independent lite review 45182313423 posted an approve verdict.
Lite also suffers 503 availability failures, including issue 2 in
45182917832. Neither model is assumed reliable merely because it exists.

## Decision

Use lite for current Developer/Reviewer overrides, keep stage checks and
bounded retries, and record all failures/fallbacks. Favor the tier that can
complete within the free service constraints. No paid fallback.

## Alternatives

Keep flash as default: rejected operationally for now because its observed
calls did not complete. This is not evidence that flash writes worse code.
Another provider/project: deferred until the current route is exhausted.

## Consequences and experiment caveat

E1's original controlled model-tier comparison is incomplete. Transport
handling and pacing changed between attempts, so the observed availability
contrast is confounded, not causal proof of model superiority. A clean
comparison should hold harness revision, issue, limits and prompts fixed.
