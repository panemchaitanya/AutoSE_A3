# ADR-007: Checks - mechanical first, LLM judge second, code decides

- Status: Accepted
- Decision area: D7 (Checks)

## Context

Every stage boundary needs a pass/fail decision. The failure mode to design
against is the agent declaring its own work done - "tests pass" written by
the agent that wrote the tests is a claim, not a check.

## Decision

Two layers at every boundary, and **the final decision is always mechanical**:

1. **Mechanical checks** (decisive):
   - Requirements: a lint parses `spec.md` - every acceptance criterion must
     be given/when/then or contain a measurable threshold, and none may use
     the vague-word list from my A1 skill's T3 rule.
   - Design: every file path named in `design.md` must exist in the repo or
     be explicitly marked NEW; the plan must name files and functions.
   - Implementation: `python -m compileall` on changed files and an import of
     the package must exit 0.
   - Testing: `pytest` exit code 0 for the new tests and the full suite.
   - Release: the PR exists and its CI check runs are green.
   - Review: the verdict is a JSON object with a required schema
     (`verdict`, `findings[]` with file/line evidence, `classification`).
2. **LLM judge** (advisory, used where the check is semantic): for stages 1
   and 2 a separate judge call with a rubric confirms the criteria are
   testable / the plan is coherent. The judge can fail a stage but cannot
   pass it alone - it can only veto.

The controller (`controller.py`) combines the layers and records both
outcomes in `state.json`.

## Alternatives considered

- **LLM judge everywhere.** Rejected: judges share blind spots with the
  models they judge and can be swayed by confident prose; anything runnable
  should be run.
- **Mechanical only.** Rejected: "all acceptance criteria are testable" and
  "the plan is coherent" are semantic claims a regex cannot settle; the lint
  catches form, the judge catches meaning.
- **Agent self-report trusted.** Rejected outright; that is not a check.

## Consequences

- Pass/fail is reproducible: re-running the checks without any model gives
  the same verdict for stages 3-6.
- The judge's veto record is kept, which gives the report real data on how
  often mechanical and semantic checks disagree (threats to validity).
