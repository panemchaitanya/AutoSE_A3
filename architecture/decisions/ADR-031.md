# ADR-031: Remind the SpecWriter of three frequent, already-checked defects

Status: proposed (post-disclosure, after runs 21 to 23). Merge only between runs.

## Context
Requirements failed in runs 21 and 23 (#39) on defects the existing rules already forbid:
a truncated table separator row (`|---|---|---|>` and `|---|---|---|-`, ADR-029 now names
them), a requirement whose text carried a number taken from an ASM default (E3), and a
STATED requirement that named a mechanism the source did not (E4). The SpecWriter model is
flash-lite; the rules were in the skill but not repeated near the point of writing.

## Decision
Append a short "frequent defects" reminder to the A3 profile that is included in the
SpecWriter and judge skill text. It restates table format, E3 and E4. It adds no rule, removes
none, and changes no check, judge or limit.

## Consequences
New harness identity (prompt text is hashed). Not a claim that requirements will pass; the
checks and the judge still decide.

## Tests
`test_developer_feedback.py::test_profile_reminds_of_frequent_spec_defects` plus the full
suite.
