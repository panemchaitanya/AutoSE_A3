# ADR-026: Correction attempts edit the current bundle version in place

## Status

Accepted, 25 November 2026, 04:25 IST, late work. Extends ADR-024. Checks, the
2-attempt bound, step cap and models are unchanged.

## Context

Runs 45501659488 (#38) and 45497498216 (#37) both failed Stage 1 with "A1 SRS/REGISTER
missing for selected bundle ... v2; components are never mixed across versions". In
run 45501659488 attempt 1 failed the semantic check (UNSET priority marked READY).
The correction attempt then wrote a new, partial v2 bundle instead of fixing v1,
because the correction task told it to "preserve earlier version history", which the
skill reads as "create a new version". The bundle check correctly rejected v2.

## Decision

The correction task text now tells the SpecWriter to edit the existing SRS, REGISTER
and VALIDATION files of the current version in place and not start a new version
number. Prompt-only. The ADR-024 digest guard still requires a real content change.

## Consequences

New harness identity. Effect unproven. Earlier runs are a different configuration.
