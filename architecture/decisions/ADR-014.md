# ADR-014: Bounded file reads and rolling exact context

- Status: Provisional operational recovery
- Decision areas: D3, D4, D9
- Amends: ADR003 hand-off size, ADR009 operational availability

## Context

Repeated503 failures persisted under two free projects and multiple models.
Five alternative-model probes timed out or503. Tiny calls returned quickly,
and a full Tester prompt with a short task/schema also returned. This does
not prove context length caused503, but supports testing a smaller request
shape rather than repeating the same path. Evidence is in results/probes.

## Decision

Read files in numbered ranges of at most160lines, defaulting to the first
range. Keep original task plus the latest four exact action/observation
pairs rather than an unbounded conversation. Cap tool observations at12k
characters and output allowance at4096tokens. Preserve full transcripts as
artifacts. Explicitly tell roles to reread source if needed. Tests and all
stage checks are unchanged. Hidden tests remain inaccessible.

## Alternatives

Continue identical retries: produced repeated503. Another listed free
model: five real probes did not yield usable role actions. Paid billing:
not authorized and not shown to solve service unavailability. Skip testing:
violates the assignment and is not a recovery option.

## Consequences

Lower request sizes, but more reads and forgotten intermediate observations
are possible. This is not a proven availability fix or quality improvement.
Current offline harness tests cover numbered ranges and missing end bounds.
Record actual outcomes and supersede this decision if the trial fails.
